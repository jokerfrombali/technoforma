Fasad və interyer üçün təbii daş

Təbii daş ən davamlı və tanınan fasad materialıdır, lakin hər daş növünün öz xarakteri var: sıx qranit və bazalt sokl və döşəməyə davam gətirir, yumşaq əhəngdaşı, balıqqulağı daşı və qumdaşı asan emal olunur və isti faktura verir, travertin və mərmər vurğulu səthlərdə yerinə düşür, oniks isə interyerdə işıqlandırma ilə açılır.

Bölmədə daş növlərinin xüsusiyyətləri və müqayisəsi, emal növləri və plitələrin qalınlığı, quraşdırma üsulları və soklun üzlənməsi, daşın qorunması və duz çıxıntıları ilə mübarizə, Hindistan, Türkiyə, Çin və İrandan idxal, alışdan əvvəl düzülüş və 3D-vizualizasiya, həmçinin qiymətin nədən formalaşdığı və obyekt üçün daşı necə sifariş etmək — nümunədən tədarükə qədər — haqqında məqalələr var.

Ayrı məqalə şirkətin çox işlədiyi Dağıstan daşına — Şimali Qafqazın əhəngdaşı və dolomitlərinə həsr olunub.

Tədarük və quraşdırma — «Təbii daş: tədarük və quraşdırma» səhifəsində.
